# WBook

Общая веб-библиотека и читалка с показом одного слова. Удерживайте область со словом: вверх — быстрее, вниз — медленнее, отпускание — пауза. Длинные слова автоматически уменьшаются по фактической ширине, остаются в одну строку и сохраняют выделенную букву в центре. Ниже доступен полный текст; нажатием на слово можно выбрать место. Есть запуск без удержания, управление пробелом и стрелками, поиск книг и локальное сохранение прогресса.

## Запуск

Node.js 22.13+.

```powershell
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_cloudy_madame_web.sql
npm run dev -- --hostname 0.0.0.0 --port 5173
```

С телефона в той же локальной сети откройте сетевой адрес, напечатанный сервером, например `http://192.168.0.136:5173/`. Компьютер должен оставаться включённым. Данные локального сервера находятся в `.wrangler/state`; данные размещённой версии хранятся отдельно в D1/R2.

## Форматы

TXT (UTF-8, UTF-16, Windows-1251), EPUB (по порядку spine), FB2, FB2.ZIP с одной книгой, DOCX, PDF с текстовым слоем, MOBI/AZW3 без DRM. Распознавания сканов нет. До 25 МиБ на файл, 10 МиБ извлечённого текста, 80 МиБ распакованного контейнера. Исходники и текст сохраняются в R2, каталог — в D1. Личный прогресс хранится в localStorage по id книги.

Импорт: JSZip, PDF.js и MIT-парсер [foliate-js](https://github.com/johnfactotum/foliate-js). PDF worker из `pdfjs-dist/legacy/build/pdf.worker.min.mjs` включён в public; при обновлении PDF.js его нужно обновить одновременно с библиотекой. Архивы разбираются локально в браузере. Для больших EPUB возможна короткая задержка при извлечении; PDF сообщает номер страницы.

## Проверки

```powershell
npm test
npm run typecheck
node tests/library.integration.mjs
npm run build
```

Интеграционная проверка требует работающего локального сервера и добавляет одну тестовую книгу. MOBI/AZW3 fixtures: свободно распространяемые версии [Alice's Adventures in Wonderland, Project Gutenberg](https://www.gutenberg.org/ebooks/11), файлы `11.kindle.images` и `11.kf8.images`. Остальные контейнеры генерируются тестами. Для реального сенсорного поведения нужна дополнительная проверка на физическом телефоне.

## Размещение

По решению пользователя от 2026-10-31 приложение запускается **только локально**, с доступом по сети через `0.0.0.0:5173`. Не публиковать и не отправлять изменения на внешний хостинг без нового явного запроса пользователя. Обычный `npm run build` выполняет только сборку. Привязки D1/R2 в `.openai/hosting.json` нужны также для локального хранилища; локальные книги находятся в `.wrangler/state`.
